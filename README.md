# Рядом

[![CI](https://github.com/ifmmaime/ryadom-suppliers/actions/workflows/ci.yml/badge.svg)](https://github.com/ifmmaime/ryadom-suppliers/actions/workflows/ci.yml)

«Рядом» — прототип сервиса для первичного поиска и сравнения поставщиков продуктов питания и упаковки. Он помогает закупщику быстро сузить список компаний, увидеть полноту доступных данных и перейти к официальному источнику для уточнения условий.

> [Открыть прототип на Vercel](https://ryadom-suppliers-seven.vercel.app/) — доступен без регистрации.

[Репозиторий](https://github.com/ifmmaime/ryadom-suppliers) · [Проверенные сценарии](docs/QA.md)

![Интерфейс каталога поставщиков](docs/preview.webp)

## Основной сценарий

1. Ввести товар или выбрать категорию.
2. Указать город или регион и получить подходящих поставщиков.
3. Добавить до трёх компаний в сравнение по единым критериям.
4. Сохранить интересные варианты и рабочие заметки в браузере.
5. Перейти на официальный сайт или страницу контактов поставщика.

Сервис не рассчитывает скрытый рейтинг. Он показывает, какие сведения доступны, а какие нужно запросить у поставщика. Причина рекомендации формулируется через наблюдаемые данные: совпадение категории и региона, наличие контактов, условий доставки, минимального заказа, цены и документов.

## Данные и достоверность

В прототипе используется небольшой вручную собранный каталог реальных компаний. У каждой записи есть ссылка на источник и дата проверки. Если цена, минимальный заказ, сертификаты или доставка не опубликованы, интерфейс показывает «По запросу» или «Нет данных» вместо предположения.

Это демонстрационный каталог без фонового парсинга. Перед закупкой пользователь должен подтвердить актуальные условия напрямую у поставщика. В рабочей версии статический источник можно заменить API или отдельным процессом сбора и модерации данных, не меняя пользовательский сценарий.

## Технологии

- React и строгий TypeScript;
- Vite для разработки и сборки;
- CSS с семантическими дизайн токенами;
- `localStorage` для избранного и заметок;
- Vitest для проверки фильтрации, сортировки и локального состояния.

Приложение работает полностью в браузере: сервер, учётная запись и ключи API для демонстрации не нужны.

## Локальный запуск

Требования: Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Vite напечатает локальный адрес в терминале.

## Проверка

```bash
pnpm check
pnpm build
```

`pnpm check` запускает проверку типов, линтер, 23 теста логики и пользовательских сценариев, а также проверку форматирования. `pnpm build` создаёт статическую production-сборку в `dist/`.

## Публикация на Vercel

Готовую сборку можно опубликовать без подключения GitHub: выполнить `pnpm build`, в Vercel выбрать **New Project → Choose a folder to deploy** и загрузить папку `dist/`. Также можно загрузить ZIP с содержимым этой папки. Для обновления в форме загрузки выбрать **Deploy to an existing project instead** и указать `ryadom-suppliers` в команде Aids1999.

Для автоматических публикаций из GitHub:

1. Импортировать репозиторий в Vercel.
2. Выбрать Vite или оставить автоопределение фреймворка.
3. Использовать команду сборки `pnpm build` и каталог результата `dist`.
4. Переменные окружения не требуются.

После подключения репозитория отправка изменений в выбранную ветку запускает новую публикацию.

## Границы прототипа

- Каталог ограничен и не заменяет проверку контрагента.
- Данные не обновляются автоматически.
- Заметки и избранное хранятся только в текущем браузере.
- Переход к поставщику не означает отправку заявки: связь происходит на его официальной площадке.

Ключевые решения описаны в [docs/DECISIONS.md](docs/DECISIONS.md), а соответствие заданию — в [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md).
