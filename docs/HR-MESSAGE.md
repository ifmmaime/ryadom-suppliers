# Сообщение HR

Здравствуйте! Выполнил тестовое задание: собрал прототип «Рядом» для поиска и сравнения поставщиков продуктов питания.

Основной сценарий — фильтрация по товару и региону, сравнение до трёх поставщиков по единым условиям, избранное, заметки и переход к официальному контакту. В каталоге используются реальные компании со ссылками на источники; отсутствующие цены и условия явно отмечены и не додуманы.
