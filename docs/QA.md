# QA отчёт

Проверка выполнена локально в браузере на `localhost:5174`. Снимки реализации и исходный концепт сохранены в локальном QA архиве `tmp/test-assignment-2026-10-29/` вне репозитория.

## Функциональные сценарии

- На мобильном экране 390 × 844 выбраны «Молочная продукция» и Санкт-Петербург. Выдача сократилась до шести поставщиков, включая «ЭкоНива Professional Line» и Alternative HoReCa.
- Два поставщика добавлены в сравнение. Открылось нативное диалоговое окно с таблицей; широкая таблица прокручивается внутри окна по горизонтали.
- Заметка добавлена в карточке поставщика и сохранилась после перезагрузки страницы.
- «Ароса» добавлена в избранное. Раздел показал одного поставщика; после удаления появилось пустое состояние, кнопка вернула полный каталог.
- Нажатие `Escape` закрыло диалоговое окно и вернуло фокус на вызвавший элемент.
- После поиска молочной продукции текст заменён на «мясо», затем выбрана категория «Мясо и птица»: выдача учитывает новый текст и включает «Мираторг HoReCa».
- После поиска по Москве регион заменён на Казань, затем выбрана «Упаковка»: в выдаче остаётся DANAFLEX. Ранее отправленный регион не используется вместо текущего значения формы.
- Вариант «Регионы России» доступен в фильтре и возвращает шесть компаний с широкой или всероссийской географией; доступность в конкретном городе не предполагается автоматически.
- После отправки формы с клавиатуры фокус находится на заголовке результатов с видимой рамкой. Ссылка «Перейти к содержимому» переводит фокус на `main`.

На мобильном экране ширина документа составила 375 px при viewport 390 px: переполнения страницы по горизонтали нет. Все семь изображений интерфейса загрузились.

## Автоматические проверки

- `pnpm install --frozen-lockfile` — успешно.
- `pnpm check` — успешно: TypeScript, ESLint, 27 тестов и Prettier.
- `pnpm build` — успешно.
- [GitHub Actions на Ubuntu](https://github.com/ifmmaime/ryadom-suppliers/actions/workflows/ci.yml) проверяет каждый push в `main`: установку по lockfile, типы, линтер, тесты, форматирование и production-сборку. Для оценки конкретной версии нужно выбрать запуск с соответствующим commit SHA. Версия pnpm берётся из `packageManager` без дублирования в CI.
- Все 12 ссылок на официальные источники вернули HTTP 200; названия страниц сверены с поставщиками. Адрес почты Alternative HoReCa с доменом `ahoreca.su` опубликован на сайте `ahoreca.info`.

## Осознанные отличия

- В концепте показано восемь компаний, в рабочем каталоге — 12 реальных поставщиков.
- Реальные условия поставки длиннее демонстрационных строк концепта, поэтому карточки и подробный просмотр допускают больше текста.
- На мобильном экране сравнение использует горизонтальный свайп внутри таблицы вместо уменьшения содержимого до нечитаемого размера.

После коррекции фотографий сделаны повторные снимки десктопа и мобильного экрана. Итоговый десктопный экран сохранён в [preview.webp](preview.webp). Ключевые тексты заголовка, поиска и навигации сохранены; добавлена поясняющая строка результатов. Существенных визуальных ошибок после правок не обнаружено.
