# Соответствие заданию

| Требование              | Реализация                                              | Как проверить                                                  |
| ----------------------- | ------------------------------------------------------- | -------------------------------------------------------------- |
| Поиск по категории      | Строка поиска и категории каталога                      | Ввести товар или выбрать категорию, проверить изменение выдачи |
| Учёт города или региона | Фильтр региона учитывает географию поставщика           | Выбрать регион и проверить состав результатов                  |
| Основная информация     | Карточка показывает специализацию, город и описание     | Открыть карточку поставщика                                    |
| Контакты и источник     | Доступны опубликованные контакты и официальный источник | Перейти по ссылке из карточки или подробного просмотра         |
| Помощь в выборе         | Сравнение до трёх компаний и объяснимая полнота данных  | Выбрать поставщиков и открыть сравнение                        |
| Дополнительные условия  | Отдельные поля для заказа, цены, документов и доставки  | Проверить известные поля и честные состояния «По запросу»      |
| Заметки                 | Заметка сохраняется локально                            | Добавить текст, обновить страницу и проверить сохранение       |
| Избранное               | Выбранные компании сохраняются локально                 | Добавить поставщика, обновить страницу и открыть избранное     |
